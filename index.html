📡 Связать с пультом (биндинг)

  1. Вставь аккумулятор в дрон (USB можно не вынимать)
  2. На пульте: SYS → Tools → ExpressLRS
  3. Нажми Bind
  4. Жди — лампочка дрона перестанет мигать

🎛️ Как дрон летает

Сложность
Пиды
Меняй по чуть-чуть. Стало хуже — верни назад. Ничего не сломается, дрон просто будет летать иначе.
Пиды — это «мозги» дрона. Они держат его ровно. Меняй только если дрон дрожит или плохо держит угол.
